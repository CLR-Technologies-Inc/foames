- PR comment watching now covers every open pull request in resumable batches, limits activity to repository owners, members and collaborators, labels comment text as untrusted data, and retries activity after interrupted or unsuccessful delivery. Reviews retain their state even when their body is empty.
- Benchmark sandbox images rebuild installed npm agent packages by name, including agents selected with a version or dist-tag, while retaining their required native installation scripts.
- Python agent image dependencies now require a fully pinned requirements lockfile with hashes, selected through `PIP_AGENT_REQUIREMENTS`; the unverified `PIP_AGENTS` override is refused.
