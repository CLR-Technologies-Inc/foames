# Did the kaizen event really cut changeover time by 70 percent?

Plant A is a contract machine shop. Its horizontal machining center 7 used to be changed over only on first shift, because a changeover took a whole shift, so second and third shifts ran long batches. A kaizen event with video, a spaghetti diagram and a set-up analysis produced standard work for the changeover.

A NIST Manufacturing Extension Partnership success story about a shop like this (<https://www.nist.gov/blogs/manufacturing-innovation-blog/success-story-improvement-effort-reduces-changeover-time>, a US government work) reports a changeover of 8 hours 20 minutes cut by 70 percent. Plant A's FoaMES site records the work center's Setup state. The operations manager wants FoaMES to say what reduction the machine's own states show.
